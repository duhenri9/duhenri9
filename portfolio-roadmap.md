## Truth rules

- **Roadmap is not availability.** Documentation and tests are scoped to the exact implementation and branch.
- **Preview is not production.** A Draft PR is not shipped functionality.
- **Observed is not inferred.** Model outputs are not independent proof of their own correctness.
- **Governance is not a certification.** A design informed by security standards is not a compliance claim.

Each step is promoted only after an explicit acceptance decision and retained evidence.
